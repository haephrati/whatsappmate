# WhatsAppSender

C++ helper (`SGWhatsApp`) for the WhatsAppMate group text API, plus a small Visual Studio sender project.

Open `WhatsAppSender.sln` in Visual Studio.

## Unit tests

`Tests/whatsapp.test.js` checks the published API host, path, and `SGWhatsApp` class name (not member credentials). Run `node Tests/whatsapp.test.js`.
